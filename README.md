# LoRA-QLoRA-finetuning-for-LLM-using-Tunix
This script implements a memory-optimized QLoRA (Quantized Low-Rank Adaptation) finetuning pipeline for a 4-bit quantized Llama-2-7b language model using the Hugging Face Transformers and PEFT libraries. By configuring a low-rank adapter (rank of 8) to target specific attention projections.
